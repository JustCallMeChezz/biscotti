# biscotti ₊˚⊹ ᰔ

just... a tool to see everything about ur device... like... ur network, ur speed, and what ur phone actually is... all u can know here...

website ˖ https://justcallmechezz.github.io/biscotti/ <br>

<br>

## ୨୧ ˙ʚ about ɞ˙ ୨୧

╭── ꒰ა ♡ ໒꒱ ───────── · · · ·

biscotti shows ur public ip and rough location, runs a speed test with a live ping graph, and tells u whats inside ur device. made to feel at home on android, but it works in any browser. theres also a toggle that finds ur phones real name and specs, its off by default and only shows up on android browsers that can share the model

`overview` `speed` `device` `settings`

╰──── ꒰ა ♡ ໒꒱ ───────── · · · ·

<br>

## ꒰ა how to use ໒꒱

╭── ꒰ა ♡ ໒꒱ ───────── · · · ·

1. open the [website](https://justcallmechezz.github.io/biscotti/)
2. tap install in settings to keep it on ur home screen
3. look around, tap start test, and checks all things there ♡

no build, no frameworks. to host it urself just drop the folder on any static host with https

╰──── ꒰ა ♡ ໒꒱ ───────── · · · ·

<br>

## 𖹭 ˙ʚ privacy (⸝⸝ᴗ﹏ᴗ⸝⸝) ᶻ 𝗓 𐰁 ɞ˙ 𖹭

╭── ꒰ა ♡ ໒꒱ ───────── · · · ·

nothing is stored on a server, no accounts, no trackers. ur settings and last speed tests stay in ur browser only, and the copied device report never has ur ip in it

the only things that leave ur device are ip lookups, speed tests, fonts, the country flag, and (only if u turn on exact device name) one device list and one spec file

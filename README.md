# biscotti ₊˚⊹ ᰔ

just... a tool to see everything about ur device... like... ur network, ur speed, and what ur phone actually is... all u can know here...

website ˖ https://justcallmechezz.github.io/biscotti/ <br>

<br>

## ୨୧ ˙ʚ about ɞ˙ ୨୧

╭── ꒰ა ♡ ໒꒱ ───────── · · · ·

biscotti shows ur public ip and rough location, runs a speed test with a live ping graph, and tells u whats inside ur device. made to feel at home on android, but it works in any browser. it also shows the real name and specs of ur device, on by default (u can turn it off in settings). android devices are found automatically, and on any other device u can search for it by name. if the exact model isnt in the database it shows the closest match with a note that the data may be off

`overview` `speed` `device` `settings`

╰──── ꒰ა ♡ ໒꒱ ───────── · · · ·

## ꒰ა how to use ໒꒱

╭── ꒰ა ♡ ໒꒱ ───────── · · · ·

1. open the [website](https://justcallmechezz.github.io/biscotti/)
2. tap install in settings to keep it on ur home screen
3. look around, tap start test, and checks all things there ♡

no build, no frameworks. to host it urself just drop the folder on any static host with https

## 𖹭 ˙ʚ privacy (⸝⸝ᴗ﹏ᴗ⸝⸝) ᶻ 𝗓 𐰁 ɞ˙ 𖹭

╭── ꒰ა ♡ ໒꒱ ───────── · · · ·

nothing is stored on a server, no accounts, no trackers. ur settings and last speed tests stay in ur browser only, and the copied device report never has ur ip in it

the only things that leave ur device are ip lookups, speed tests, fonts, the country flag, and (unless u turn off exact device name) one device list and one spec file
